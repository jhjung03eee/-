# 대구 스마트시티 통합 플랫폼 구축 입찰공고

## 1. 사업 개요

- 사업명: 대구 스마트시티 통합 플랫폼 구축
- 발주기관: 대구광역시 스마트도시과
- 사업예산: 2,400,000,000원
- 사업기간: 계약체결일로부터 14개월
- 사업지역: 대구광역시 (지역제한)
- 입찰방식: 협상에 의한 계약

## 2. 추진 배경 및 목적

교통·환경·안전 데이터를 통합하는 도시 데이터 허브를 구축하여 데이터 기반
행정 체계를 확립하고자 한다.

## 3. 과업 범위

- 도시 데이터 수집·연계 파이프라인 구축
- 통합 데이터 분석 및 시각화 플랫폼 개발
- 개방형 API 게이트웨이 구축
- 클라우드 인프라 구성 및 운영 이관

## 4. 기술 요구사항

- 데이터 처리는 python 기반으로 구현한다.
- 대시보드는 react 기반으로 개발한다.
- 대용량 시계열 데이터 처리 성능을 확보하여야 한다.

## 5. 입찰참가 자격요건

- 본 입찰은 지역제한 경쟁입찰로, 입찰공고일 전일부터 계약체결일까지 법인등기부상
  본점 소재지가 대구광역시인 업체만 참가할 수 있다.
- 「소프트웨어 진흥법」에 따른 소프트웨어사업자 신고를 필한 업체
- 최근 2년 이내 공공 데이터 플랫폼 구축 실적 보유 업체

## 6. 낙찰자 결정 방법

- 기술평가 80점, 가격평가 20점으로 종합평가한다.

## 7. 대가 지급 방법

- 선금 지급 가능, 기성 3회 분할지급

## 8. 계약 조건

- 지체상금률 1일 0.075% 적용
- 하자보수 보증기간 24개월
- 소스코드 일체를 발주기관에 인도하여야 한다.
